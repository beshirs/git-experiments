# Git Basics Lab for CS 347

## Part 1: Basic Git Workflow
1. Open github and create a new repository
2. Run this in the terminal: ' cd ' and then ' git clone {your repo} '
3. Open in VScode and create a new file 
4. In terminal, run ' git add {file name} ' 
5. 'git commit -m '{file changes}' '
6. 'git push origin main'
7. Go to github to view changes to files.
